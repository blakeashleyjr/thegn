**Other actionable findings**

- **Reconnect retries stop after one failed attach.** The advertised attempt budget covers successful reattachments that immediately lose the stream; a failed reattachment with unknown absence exits. Transient failures need bounded retries of the same session, without opening unproven duplicates. Source-confirmed, no separate live reproduction.
- **Live Logs can stop following after rotation or truncation.** The file provider opens one descriptor and never checks replacement identity or resets after truncation. Rename-based rotation can leave the panel following the old file. Source-confirmed and pre-existing; no live panel freeze was reproduced.
- **Credential lookup sits outside the native request timeout.** With no environment token, unbounded `gh auth token` executes before the timed request. A stuck helper can stall a worker. No stuck live helper observed.
- **Git metadata watches are both incomplete and invalid in linked worktrees.** A real tiny Cargo fixture retained an old embedded SHA after a metadata-only commit; an unchanged linked build reran because `../../.git/HEAD` was missing. This is stronger evidence for THE-575 than the earlier suspected cause.
- **Telemetry cannot establish end-to-end display latency or total CPU.** The normal frame path is asynchronous; input stamps are overwritten/consumed by the next frame without causal response tracking, and input handlers are omitted from idle busy-time accounting. Publish receipt, queue, completed-write and sample-count metrics with accurate names.
- **Hydration and incremental rendering deserve controlled measurement.** The primary capture contains 1,249 model-build records with median 1,062 ms wall time. Supplemental slow windows contain 94–98% incremental frames and 26 combined PTY budget hits. Periodic whole-screen resync is counted as incremental; it is a candidate to measure, not a proven cause. Temperature causation and a build-to-build regression remain unestablished.
- **Availability and “collected” messages overstate outcomes.** Backend availability failure is not proof of a stopped service, and a void cleanup return is not proof a branch was collected. Typed outcome reporting is needed at both boundaries.
