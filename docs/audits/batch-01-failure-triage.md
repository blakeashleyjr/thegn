## Direct ownership evidence

Read-only metadata observation in this execution namespace: effective UID 1000;
`/` owner UID 65534, mode 0755; `/tmp` owner UID 65534, mode 01777; private
integration directory owner UID 1000, mode 0755. `platform/gate_path.rs:55-72`
rejects ancestors owned by neither the effective UID nor root. Its sticky-writable
ancestor exception requires owner UID 0. `Directory::open` walks every component
from `/`, validates `/tmp` during the walk (`:132`), and revalidates pinned paths
including `/` (`:169`). Thus placing a UID-1000 fixture below `/tmp` cannot satisfy
this namespace's existing ownership guard. No bypass or ownership change is proposed.

`CanonicalHistory::capture` wraps `Directory::open` with the verified-local-path
message (`canonical_history.rs:209-212`). `cleanup::Verified::probe` invokes that
capture before its dirty/filter/worktree checks and reduces the error to its
outer string (`merge_cleanup.rs:384-393`). That explains why some logs expose
only the history error and others assert on a later reason that was never reached.

Gate execution prepares the verified workspace before setup/command execution
(`integrate_gate.rs:706-710`), and `gate_tip` converts preparation errors into an
infrastructure verdict (`integrate.rs:722-733`). The concurrent-gate fixture waits
for a marker from that command, then asserts the marker before printing the
original verdict (`integrate_gate_tests.rs:747-765`). Its missing marker is therefore
consistent with early refusal, rather than proof of a production deadlock.
The same ordering explains setup-exit, HEAD-replacement, lock-identity and filter
expectation failures; their lost inner diagnostics prevent direct attribution.

`attempt_land` also captures canonical history before landing and wraps admission
failure into a generic infrastructure result (`integrate.rs:1387-1401`). Cleanup
calls `Verified::probe` before the later queue/resource/hook/removal decisions
(`merge_lifecycle.rs:354-372`). Source ordering explains unchanged worktrees,
empty collected lists, absent pre-destroy rendezvous and unexpected refusal text
in the affected integration/cleanup/sweep fixtures. Their intended later contract
still needs execution in a compatible environment.
