# Runtime workers

Source references below use the launch base `657f117b45`. A thread's `JoinHandle`
is called owned only when the source stores it or joins it; otherwise ownership is
reported as detached. A channel send is not a stop acknowledgement. “Unverified”
means the source does not establish a process-wide bound or a stop acknowledgement.

## Scope and claims

**Zero UI polling** is the event-loop contract: while idle, the UI loop blocks in
`termwiz::Terminal::poll_input(None)` and does not wake on a timer it owns. The
contract is enforced by `test/idle-poll-guard.sh` and `idle_poll::poll_timeout`
(`crates/thegn-host/src/idle_poll.rs`). It does not imply that every worker in the
process has no timer.

**Zero hidden-worker scheduled wakeups is not a process-wide claim.** The splash
spinner wakes every 250 ms only while an active splash is visible
(`crates/thegn-host/src/loading/ticker.rs:22,77`); metrics scrape at their configured
interval while targets are configured (`crates/thegn-host/src/metrics.rs:78-83,111`);
the hydration ticker schedules refresh slots on a 500 ms base while its refresh
service is running (`crates/thegn-host/src/hydrate_refresh_ticker.rs:232-280`);
merge and PR-agent lease heartbeats wait for their renewal deadlines
(`crates/thegn-host/src/merge_driver_claim.rs:120-131` and
`crates/thegn-host/src/pr_agent_lease.rs:77-80`); the file-log tail retries a missing
log directory every 30 seconds (`crates/thegn-svc/src/log/provider.rs:22-25`). Other
one-shot deadlines and retries are listed below. These are worker wakeups, not UI
polls.

The wake classes used here are: **(a)** required visible work; **(b)** required
background maintenance; **(c)** retry/work already in hand; **(d)** avoidable hidden
polling. “No explicit cap” means the source does not enforce an aggregate cap for
that thread family; it is not a claim that the operating system has no limits.

## How to keep this current

Update this inventory in the same change that adds or changes a long-lived worker,
runtime, scheduled wake, queue cap, or child fan-out. Cite the spawn site and the
owner/cancel path, and distinguish a sent result from an acknowledged stop. Use
`platform/thread_census.rs` for thread samples and `THEGN_PERF=1` for runtime
park/unpark and wake-source attribution. Follow THE-665 (2026-10-19): measure only
under competing load; change nothing without evidence.
