# WS05-P0-06 - Seatbelt primitive spike on a Mac (19 cases)

**Question.** Do the Seatbelt cornerstones hold on a real Mac (parameterised profiles, bad-profile failure, nested sandbox-exec, `file-map-executable`, `preference-domain`, exact-path pty rules, firmlink spellings, symlinked private HOME, cache dir, IP-only network with unix sockets, loopback port binding, violation log format, `logd`)?

**Needs (macos-device).** The owner's Apple-silicon Mac on macOS 26.x AND a macOS 15 host (a VM or hosted runner is fine: these cases need no virtualisation). `/usr/bin/sandbox-exec`, `python3`, `nc`, `curl`, `script`, `tmux` (optional), `log`. Run from an INTERACTIVE terminal (the PTY cases need a controlling tty; open a second terminal tab so V-PTY-07 has another `/dev/ttysNNN` to attack). For V-VIO-01 run once as an admin user and once as a non-admin user. No accounts, no cost. Creates only: scratch dir under `$TMPDIR`, `/tmp/tgspike-u-<pid>`, a TCP listener on 18098, `defaults` domain `thegn.test.secret`, `$HOME/.tgspike-path-<pid>`, `DARWIN_USER_CACHE_DIR/tgspike-layout`, a tmux socket `tgspike`; all removed by trap.

**Script.** `scripts/spikes/ws05-p0-06.sh OUTDIR`; evidence `OUTDIR/WS05-P0-06.evidence.jsonl` in the WS05-P0-01 line format (shared `lib-cases.sh` runner; do not fork a second one). Each probe is a hand-written `sandbox-exec -p` using `(allow default)` plus targeted denies so one primitive is tested at a time; the exact profile text is in each line's `cmd`. The case ids: V-SB-01,02,03,04,05,07; V-PTY-01,04,05,07; V-PATH-03; V-HOME-01,02; V-UNIX-01; V-NET-01,06; V-VIO-01; V-NEST-02; V-LOG-01 (19 ids, the plan says "about 16").
