# WS03-P0-01 - confirm the landlock 0.4.7 and seccompiler 0.5.0 APIs on an ABI 10 host

**Question.** Does each Landlock and seccomp symbol the Linux confinement design relies on exist and behave as claimed (UDP `AccessNet` rights, `AccessFs::ResolveUnix`, `Scope::{AbstractUnixSocket, Signal}`, per-right `CompatLevel`, `RestrictionStatus` fields, seccompiler `Dword`/`MaskedEq`, seccompiler's own arch prologue, the `open_tree_attr` number), and do both crates fit MSRV 1.89?

**Needs.** The dev host: Linux x86_64, kernel 7.2.15, Landlock ABI 10 (the script warns when the ABI is lower and the UDP/ResolveUnix answers are then not representative). Rust toolchain (the workspace's, 1.89 MSRV; install `rustup toolchain install 1.89` for the MSRV build). Network for crates.io. No accounts, no cost. It compiles a small crate (two dependencies): run once on a quiet machine.

**Script and probe.** `scripts/spikes/ws03-p0-01.sh OUTDIR` building `scripts/spikes/probes/confine-apis/` (standalone crate with its own `[workspace]` table, so it never touches the thegn workspace or `Cargo.lock`; the script builds a COPY under OUTDIR). One cargo feature per symbol (`udp`, `resolve_unix`, `scope_abstract`, `scope_signal`, `libc_open_tree_attr`): a symbol that is missing in the crate fails to compile in isolation and is recorded `COMPILE ERROR`. Every irreversible call (`restrict_self`, `apply_filter`) runs in a re-exec'd child.

## Steps

1. `OUT=$HOME/spike-evidence/WS03-P0-01-$(date +%F); scripts/spikes/ws03-p0-01.sh "$OUT"` (cargo build x6, a few minutes cold).
2. Triage every `COMPILE ERROR` line: it counts as "no" only if the error is a missing or renamed symbol. The UDP variant names (`AccessNet::BindUdp`/`ConnectUdp`) in `src/main.rs` are a best guess: read docs.rs for landlock 0.4.7 `AccessNet`, fix the names and re-run before concluding "no". Every "yes" needs a passing run line (fail-closed rule: an unverified symbol is "no").
3. Landlock evidence: `RESTRICTION`: read the `restriction_status=` lines for `fs-v6-hard` and `fs-v6-best` (these record the exact field names and variants of `RestrictionStatus`). The "right above the host ABI" cases (`BestEffort` vs `HardRequirement`) cannot be exercised on an ABI 10 host if the crate knows no newer ABI: run `confine-apis-spike landlock fs-v6-hard|fs-v6-best` on an older kernel host if one is available, else record it as not exercised.
4. seccompiler evidence: `seccomp-dword|masked|qword.out`: Dword/MaskedEq must show `call=high_bits ... BLOCKED(EPERM)`; the `qword` run is expected to show the bypass (`reached-ioctl`), proving why the low-32-bit compare matters. `dump-masked.out` is the disassembly for the record: `loads_args1_low=true` and `loads_args1_high=false` show the low-32-bit compare; `loads_arch_word=true` shows whether the crate emits its own arch prologue (look at the first instructions to describe its form and how it combines with the hand-written prologue).
5. `open_tree_attr`: the `uapi-*` captures give the number per arch from the kernel headers (UAPI source) and `run-libc_open_tree_attr` the libc value; record both and the source. aarch64: read `asm-generic/unistd.h` (x86_64 and aarch64 share it for new syscalls).
6. MSRV: `msrv_landlock-0.4.7`, `msrv_seccompiler-0.5.0` and `msrv_build` lines; if the build on 1.89 fails record the pin.
7. Write `docs/audits/linux-confine-2026-11/apis.md` (the only file that lands): one row per symbol with columns symbol, crate version, available (yes/no), how shown (test name = the probe case and its result), fallback if no (raw `landlock_add_rule` with `LANDLOCK_ACCESS_NET_*_UDP` constants; a hand-written BPF fragment for a seccompiler no), plus the MSRV section and the one disassembly. Discard the evidence directory; commit no probe code.

## Decision rule and downstream

- "yes" on UDP `AccessNet`: P1-05 keeps `net-udp` on Landlock ABI 10 as planned; "no": raw `landlock_add_rule` for the UDP rights (or UDP left to the seccomp stream-only filter alone).
- "no" on `ResolveUnix` or the scopes: same fallback for `unix-*`, `unix-abstract`, `signal-scope`.
- "no" on `Dword`/`MaskedEq`: P1-04 hand-writes the masked `ioctl` compare (TIOCSTI/TIOCLINUX/TIOCCONS/TIOCSETD on the low 32 bits).
- Unblocks WS03-P1-01 (openspec change), P1-04 (seccomp builder), P1-05 (Landlock builder). Do NOT add `landlock` or `seccompiler` to the workspace `Cargo.toml`/`Cargo.lock`; they enter only through WS03-P1-02.

**Time.** About 1 hour including triage and the record.
