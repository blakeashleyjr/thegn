# WS05-P0-01 - macOS on-device evidence: Apple `container` (V-AC-01..05) and podman/docker (V-OCI-01..03)

**Question.** What does Apple `container` actually do for `network none`, internal networks, `--ulimit nproc`, labels and `--version` (V-AC-01..05), and what do the podman/docker engines print on the Mac (V-OCI-01..03)?

**Needs (macos-device).** The owner's Apple-silicon Mac on macOS 26.x with Apple `container` installed (optional per case: missing tool is recorded `skipped-not-installed`), podman, docker CLIs as available, `python3`, bash 3.2 (stock). Registry access for a small image (`SPIKE_IMAGE`, default `docker.io/library/alpine:3`). No accounts, no cost. The cases create an Apple internal network named `thegn-none`, containers `tgspike-*` and ONE listener on TCP 18099 on all interfaces for V-AC-02; all removed by trap.

**Script.** `scripts/spikes/ws05-p0-01.sh OUTDIR` (on non-Darwin prints "macOS only", exits 2). Evidence: `OUTDIR/WS05-P0-01.evidence.jsonl`, one JSON line per case `{id, macos, arch, thegn_commit, cmd, rc, expect, stdout_sha, stdout_head, stderr_head, verdict}`, raw output in `OUTDIR/WS05-P0-01/<id>.out|err`. Built on `scripts/spikes/lib-cases.sh`, which the Seatbelt script (WS05-P0-06) reuses (one runner, not two). The issue's full deliverable (`test/macos/` runner, selftest, `just macos-ondevice*` recipes, README, CONTRIBUTING item 10, the `fix-macos-oci-runtimes` openspec change) is the implementing item; this script is the single-run spike form of the same cases and its `sc_case` contract can be lifted into `test/macos/lib.sh` unchanged. The Apple CLI flag forms are the planner's suggestions: each line records the argv actually run.

## Steps

1. `OUT=$HOME/spike-evidence/WS05-P0-01-$(date +%F); scripts/spikes/ws05-p0-01.sh "$OUT"` (about 10-15 min; first run pulls the image).
2. Read the computed verdict line and the per-case lines. V-AC-02 pass means "blocked" (the case expects a failing `wget`): internet blocked AND Mac host blocked is the positive branch.
3. If `container` was missing, re-run after install; V-OCI cases need only the engines you have. Also start each engine's VM (Docker Desktop, Colima, OrbStack, Rancher Desktop, Finch) once and re-run to capture `V-OCI-03` per engine (or run WS02-P3-08's script per product).
4. Commit `docs/audits/macos-evidence/<date>/` with the JSONL (review: no secrets; heads are bounded) and hand the raw V-OCI captures to WS02-P3-08. Note the host (macOS version, arch, date) in the PR.

## Decision rule (from the issue)

- V-AC-01/02: `internet=blocked` AND `host=blocked` on `container network create --internal` => positive branch for WS05-P0-02 (Apple `network = "none"` can be honoured); anything else => negative. V-AC-01 rc/stderr informs the wording of the Apple refusal.
- V-AC-03: `--ulimit nproc=N:N` accepted and forking stops near 64 => WS05-P0-04 maps `pids_limit` to it.
- V-AC-04: `--label` accepted and visible in `container ls -a --format json` => WS05-P0-04 enables labels and the GC filter.
- V-AC-05: the `container --version` format fixes the parser table in WS05-P0-05.
- V-OCI-01..03: raw captures (podman machine JSON, no-machine state text, docker contexts and engine sockets) for WS02-P3-08 and WS05-P6-02.

## Downstream

Decides WS05-P0-02, P0-04, P0-05 and feeds WS02-P3-08, WS05-P6-02, P6-04; blocks WS05-P0-06 (runner) and, without a Mac in W0, moves P0-02/P0-04 to W3.

**Time.** 15 min run, 30 min review.
