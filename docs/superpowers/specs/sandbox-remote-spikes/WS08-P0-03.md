# WS08-P0-03 - validate the machine0 MCP tool names against `tools/list`

**Question.** Do the twelve MCP tool names the machine0 provider hard-codes (`vm_create`, `vm_get_by_name`, `vm_list`, `vm_destroy`, `vm_start`, `vm_stop`, `vm_suspend`, `ssh_key_create_public`, `ssh_key_list`, `image_create`, `image_list`, `size_list`) exist on the live server? The source comments disagree about which were verified (and the module doc says `ssh_key_create` where the constant is `ssh_key_create_public`).

**Needs (paid-account).** A machine0 account with `MACHINE0_API_KEY`; optional `MACHINE0_MCP_URL` (default `https://app.machine0.io/mcp`). Tools: `curl`, `jq`. Cost: none (the run only lists tools; it creates no VM). Prerequisite for the doc edit: WS00-P1-09.

**Script.** `MACHINE0_API_KEY=... scripts/spikes/ws08-p0-03.sh OUTDIR`. Read-only JSON-RPC 2.0: `initialize` (captures any `Mcp-Session-Id`; the value is not recorded), `notifications/initialized`, then `tools/list` following `nextCursor` (bounded to 10 pages), unwrapping an SSE body. The key goes to curl through a 0600 config file, never argv, never saved. Writes `OUTDIR/WS08-P0-03/machine0_tools_list.json` (names only; raw pages beside it) and prints the drift verdict (the pure `tool_drift` logic, computed here first).

## Steps

1. `export MACHINE0_API_KEY=...`; `scripts/spikes/ws08-p0-03.sh $HOME/spike-evidence/WS08-P0-03-$(date +%F)`.
2. If the verdict names missing tools: the constant is a one-line fix each (`crates/thegn-svc/src/machine0/mod.rs`, `mod tool`); then re-run until the drift is empty.
3. After review (no secrets expected) copy `machine0_tools_list.json` to `crates/thegn-svc/tests/fixtures/machine0_tools_list.json` (top level of `fixtures/`, which holds only `ci/` today). Record the capture date.
4. The implementing item then adds `Mcp0Client::list_tools()` (via `crate::agent::block_on_provider` from `thegn env test`), `machine0::tools::ALL`, the pure `tool_drift`, the `thegn env test` output, the unit and live tests, the help line, and corrects the two contradictory doc comments in `machine0/mod.rs` with the verified date.

## Decision rule (from the issue)

`tool_drift(listed)` (names in `ALL` absent from the live `tools/list`) must be empty. A rename or removal is reported as `error: machine0 MCP tool '<name>' not found in tools/list`; extra tools are not an error. Non-empty => fix the constants and re-run until empty.
