# Support

thegn is a small, fast-moving alpha project. Here is where to go:

- **Getting started / usage:** the [README](README.md) tour and the in-app help
  (press `F1`), which mirrors the pages under [`docs/help/`](docs/help/).
- **Configuration:** every key is documented in
  [`config/config.toml.example`](config/config.toml.example); `thegn doctor`
  diagnoses your environment.
- **Bugs and feature requests:** open a
  [GitHub issue](https://github.com/blakeashleyjr/thegn/issues) using one of the
  templates.
- **Questions and ideas:** use
  [GitHub Discussions](https://github.com/blakeashleyjr/thegn/discussions) if
  enabled; otherwise open an issue with the "question" template.
- **Security issues:** do not use public channels — see [SECURITY.md](SECURITY.md).

Please search existing issues before opening a new one. There is no support SLA;
this is a personal project shared in the open.
