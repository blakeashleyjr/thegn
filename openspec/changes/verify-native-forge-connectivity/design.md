# Isolated SDK evidence composition

The nonignored parent reexecutes its current test executable with one exact,
ignored helper selector and an asserted command-local marker. Only the child
mutates global connectivity, so parallel tests in the parent cannot affect the
matrix. Private environment/cwd, null stdin and regular-file output avoid
ambient credentials, provider execution and pipe-reader ownership.

The helper explicitly installs Auto/threshold-one policy and seeds Offline
before nine reachable responses, or Online before two transport failures. It
checks actual hot state and consecutive failures, a private native circuit,
exact typed outcomes, and real Ladder native/CLI counts. Partial data plus
errors must fall through once; native success and final error classes must not.
The eleven cases use the pinned Octocrab in-memory service, no sockets or tools.

The parent shares the unchanged pre-reserved exact Child custody used by THE-611:
observation errors revoke later syscalls; failed cleanup retains child and private
root; Drop has a bounded settlement attempt. Execution is capped at ten seconds,
output is monitored at one MiB with bounded post-reap reads, explicit cleanup at
one second plus existing500ms Drop fallback. Normal success requires exact helper
PASS and one complete receipt, confirmed reap and strict TempDir close. This is
fixture child ownership, not a general escaped-tree guarantee.

The shared custody block and original THE-611 observation-error test are compared
to their prior source; only test-local visibility and rustfmt may differ in the
moved block. No Cargo feature, production API or global reset is introduced.
Root runs native fixtures, the global-success-publication counterfactual and
final lint/source/delivery gates before reviewed local-main landing.
