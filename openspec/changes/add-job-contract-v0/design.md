# Contract boundaries

The four leaf libraries use independent crate versions. Only the spec library depends on the CAS library. A publisher can export the structural schemas through `thegn_job_spec::job_schema()` and `result_schema()`. Use `JobSpec::parse_yaml` for author input and call `JobSpec::validate` on structured submissions. Effective trust, shape, budget and the final runtime evidence remain admission inputs. The portable feature set describes the execution features one candidate must support.

Hash canonical directory protobuf bytes, including executable bits and child digests. The encoder operates on supplied entries. The snapshotter must capture files consistently and enforce symlink confinement across the whole tree. The guest bootstrap schema negotiates a maximum size before subsequent framed messages. Its independent protobuf fixture includes the four-byte network-order prefix.

An `AttemptLease` models one attempt against authoritative database time. In storage, select the current shard row and verify its authenticated worker, run and epoch in the transaction that persists the transition. Look up a completed attempt only for replay of its stored receipt. Bind the fingerprint to the complete accepted publication. Expiry and the run deadline are exclusive upper bounds. Only the initial successful commit may publish manifests and meter usage. A receipt replay cannot repeat either effect.

The contract introduces no UI wake source, render work, or database migration. The first queue consumer owns its migration. Native provider adapters will connect the contract to the existing scheduler and launch admission after the durable queue can exercise the same fixtures.
