# Files in crates/thegn-host/src/cmd that print JSON without going through
# `cmd::emit_json` (a hand-rolled `serde_json::to_string_pretty(..)` /
# `serde_json::to_string(..)` + `outln!`/`println!`).
#
# The `--json` convention (cmd/mod.rs): exactly one compact JSON document on
# stdout, shape treated as a stable API, via `emit_json`. Two grandfathered
# exceptions are documented there (`notify list` NDJSON, `doctor` pretty
# object); everything else pinned here is drift to route through `emit_json`
# (or, where pretty output is the point — `config schema`, `config show` —
# through a deliberate `emit_json_pretty`).
#
# SHRINK-ONLY. Enforced by `test/ratchet.sh json-emit` in `just lint`;
# regenerate with `just ratchet-update`.
# `mcp_proxy_cmd.rs` is pinned for its `--json` status document (pretty, not
# `emit_json`) — note its OTHER `to_string_pretty` writes the agent settings
# FILE, which this stdout rule does not govern.
