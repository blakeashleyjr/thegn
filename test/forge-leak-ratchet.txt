# Files that call the GitHub CLI layer directly (`thegn_core::github::…` or a
# raw `Command::new("gh")`) instead of going through the forge seam.
#
# The forge is a provider seam (provider-seams spec): host code must talk to a
# `Forge` trait so a non-GitHub forge is an implementation, not a rewrite.
# Two kinds of entry live here:
#   IMPL  — files that *are* the GitHub transport and legitimately call gh:
#           crates/thegn-core/src/remote.rs (GitLoc::gh_command),
#           crates/thegn-svc/src/gh.rs, crates/thegn-svc/src/prq.rs,
#           crates/thegn-svc/src/issue/github.rs. These stay.
#   LEAK  — everything else, burned down to zero by the forge-seam change.
#
# SHRINK-ONLY. Enforced by `test/ratchet.sh forge-leak` in `just lint`;
# regenerate with `just ratchet-update` (RATCHET_UPDATE=1).
