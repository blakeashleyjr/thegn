# Shrink-only allowlist pinning `thegn_core::capability::SURFACE_GAPS`.
#
# One TAB-separated `<capability id>\t<surface>\t<reason>` line per excused
# (capability, surface) cell — a catalog row a surface does not implement yet.
# `#` comments and blank lines are ignored. The reason column is REQUIRED: it is
# the written justification for the excuse, restated from the row's rationale in
# SURFACE_GAPS and regenerated from it by `just ratchet-update`, so the two can
# never drift apart.
#
# SHRINK-ONLY. Enforced by `ratchet_pins_surface_gaps` (thegn-core, runs in
# `just test`): the file and SURFACE_GAPS must be the same set. Burning an
# excuse means DELETING its line here; adding one fails the build until a line
# is added. A surface a capability is *deliberately never* exposed on is
# expressed by narrowing the catalog row's surface set, never by an excuse
# (that is why nothing here is a `pairings.*` or `daemon.shutdown` row). When
# this file is empty the pin asserts SURFACE_GAPS stays empty.
#
# The debt, by surface:
#   plugin  — NONE. `host.call` dispatches every non-streaming catalog row
#             generically off the `API_CALLS` spine, so the plugin surface
#             carries no excuse at all.
#   grpc    — the control.proto mirror lags HTTP: each row is a proto message +
#             handler addition, no new logic.
#   mcp     — the state tools are not landed yet (the MCP write-tools branch
#             retires these); scope-gated container tools land with it.
#   http    — the CLI-first operator families (`secret.*`, `project.*`,
#             `containers.*`, `doctor.bundle`, `launch.preset`) run against
#             local custody today; a remote-operator route is future work.
#   cli     — `search.*` runs in-process against the worktree (never through the
#             control client, which is all `cli_control_caps` measures);
#             `containers.*` ships as the TUI Containers tab this change.
