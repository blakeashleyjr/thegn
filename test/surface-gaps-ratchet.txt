#
# One `<capability id>\t<surface>` line (TAB-separated) per excused
# (capability, surface) cell — a catalog row a surface does not implement yet.
# `#` comments and blank lines are ignored.
#
# SHRINK-ONLY. Enforced by `ratchet_pins_surface_gaps` (thegn-core, runs in
# `just test`): the file and SURFACE_GAPS must be the same set. Burning an
# excuse means DELETING its line here; adding one fails the build until a line
# is added — and the reason belongs in SURFACE_GAPS beside the entry, not here.
# A surface a capability is *deliberately never* exposed on is expressed by
# narrowing the catalog row's surface set, never by an excuse. When this file is
# empty the pin asserts SURFACE_GAPS stays empty. Regenerate with
# `just ratchet-update` after a burn-down.
#

# write-tools branch retires these).
