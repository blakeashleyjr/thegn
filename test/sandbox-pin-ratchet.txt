# Deliberate worktree-less resolver selections, keyed by enclosing function.
agent_configs.rs:resync_agent_auth  Reads profile-independent credential transfer policy only.
close_teardown.rs:background_close_with  Teardown cleanup does not launch a process.
cmd/env.rs:resolve_with_selection  Env display and image-bake use the selected env name only.
lifecycle.rs:explicit_park  Park and teardown bookkeeping does not launch a process.
lifecycle.rs:pool_env  Selects the warm-pool env name; it does not launch a worktree.
lifecycle.rs:recycle_spare  Recycles a worktree-less spare using its configured env name.
loading/track.rs:loading_context  Splash text reports the selected env while preparation resolves the pin later.
merge_cleanup.rs:settle  Merge cleanup only tears down the old launch context.
provider_factory.rs:resolve_provider_env  Resolves provider ownership and sandbox naming, not a worktree launch.
pty_drain.rs:report_pane_connect_failure  Reports provider health after a pane connection failure.
wizard.rs:new  Computes each host's effective profile default for the creation form.
worktree_lifecycle.rs:teardown_runtime  Teardown identifies the provider runtime and never starts a process.
cmd/wt.rs:create_and_register  New worktree has no registered worktree pin yet; resolves its inherited default.
cmd/doctor_pins.rs:collect  Doctor reports what an unpinned worktree would inherit; the stored pin is shown beside it, never launched.
agent.rs:launch_spec_full  Reads only the resolved env name to provision the provider repo; a profile pin sets sandbox.profile, never the env name, and the launch itself already went through the merged-pin prepare_sandbox_env_with_selection.
provision_gate.rs:heal_provider_prefix  Reads only the env's provider transport prefix to repair a stale stored row; never launches.
cmd/agent_spawn.rs:stop_target_blocking  Identifies the provider env and bound sandbox name to park after a headless run exits; it stops a sandbox and never launches a process.
