# THE-516 foundation correction — native dispatch row 503

verdict: implementation-ready

This dispatch implements the primary revision-2 corrections within the
approved foundation chunks 1–2. It does not claim THE-516 is complete.

## Implemented

- Replaced `util::git_stdout_bounded`'s predictable temporary-file spool with a
  bounded stdout pipe, a `max_bytes + 1` reader cap, a deadline, Unix probe
  process-group teardown, bounded synchronous reap, and an owned fallback
  reaper. Added injected-child regressions for idle output, oversized output,
  and a child retaining stdout after its parent exits.
- Changed Git worktree generation capture to stable `same-file` handle
  identity (device/inode on Unix and the supported same-file Windows handle
  identity), excluding mutable ctime and unstable Windows MetadataExt calls.
  Inspection now captures and rechecks the admin stamp and compares the Git
  registration/branch snapshot across the complete probe sequence.
- Bounded `worktree_instances_for_path` to a SQL `LIMIT + 1`, a checked row
  count, and a checked aggregate retained-byte budget. Added exact-limit,
  one-over, and oversized-borrowed-field regressions.
- Made legacy promotion refuse every unresolved competing claim sharing an
  exact path or `(repo_id, admin_id)` inside one transaction. It no longer
  authorizes the first row. Revision transitions reject `i64::MAX` before any
  SQLite increment.
- Added explicit raw-length preflight before Git path conversion, bounded
  display UTF-8 validation/projection, and correct Windows UTF-16 code-unit
  counting before native path allocation.
- Corrected the v69 DDL's primary-key nullability and strengthened schema
  verification for column types/defaults, CHECK clauses, index columns, and
  actual unique/partial index flags and predicates.
- Added real temporary-Git regressions for symlink/same-basename repository
  identities, newline/non-UTF-8 detached paths, replacement snapshot refusal,
  and generation stability across checkout/branch rename versus worktree
  replacement.
