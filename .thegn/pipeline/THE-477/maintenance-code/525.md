# THE-477 implementation handoff — native dispatch 525

Verdict: implementation-ready

Implemented the primary-approved THE-477 scope. No new configuration key,
refresh cadence, provider behavior, or unrelated calendar feature was added.

## Implemented

- Added the typed `ClockFormat` row policy (`H12`, `H24`, or custom strftime)
  and carried it, plus `show_date`, through `ResolvedClock` and
  `ClockReading`.
- Resolved empty row formats against the already-resolved global calendar
  12/24-hour setting, including the synthesized home row and the fallback home
  row. Unknown zones remain warn-and-skip.
- Reused and extended the existing parsed `strftime_needs_seconds` detector.
  Strict validation reports seconds-bearing row formats; tolerant config
  loading resets malformed or seconds-bearing row formats to inherited global
  settings. No ticker or cadence code was changed.
- Rendered each row from its carried policy. `show_date = true` emits the
  local `YYYY-MM-DD` and no redundant `+1d`/`-1d`; `show_date = false` retains
  the weekday and existing conditional relative marker.
- Routed formatted time/date output through THE-471's bounded
  `DisplayText::new(..., Field::ClockLabel)` projection.
- Updated Rust field docs, the config example, calendar help, and the calendar
  OpenSpec contract for inheritance, minute-safe formats, normalization,
  terminal safety, and date-cell semantics.

## Regression coverage

- Mixed inherited/custom formats and `show_date` config resolution.
- Strict rejection of `%S`, `%T`, `%r`, `%X`, `%s`, and fractional-second
  forms, escaped `%%S`, and tolerant post-process normalization.
- Reading policy propagation while preserving DST/fractional-offset and
  calendar-day delta calculations.
- Host snapshot resolution for global 12-hour inheritance and mixed rows.
- Rendered same-day/cross-day mixed rows, full-date versus relative-marker
  behavior, control-producing `%n`/`%t` output sanitization, and narrow
  clipping bounds.
