# THE-505 maintenance code handoff — native dispatch 481

verdict: implementation-ready

## Scope delivered

Implemented the primary revision for chunks 1–2 only. The core admission path
now:

- uses a statement/container-aware TOML budget scanner with per-statement
  dotted-key depth reset, quoted-key handling, nested value arrays, table/root
  member limits, multiline string line limits, decoded-tree preflight, and
  bounded JSON serialization;
- freezes present and absent environment reads, rejects environment input before
  overlay mapping when budgets are exceeded, and uses typed supplied-value
  failures for malformed enum/bool/number/port/duration inputs without warning
  prose matching or runtime warning emission during admission;
- preflights CLI entry count, aggregate bytes, key depth, and bracketed value
  structure before applying any override;
- separates pure candidate post-processing from the legacy effectful wrapper;
  admission validates raw values before clamp/drop/fallback normalization and
  never installs remote/network process globals;
- keeps source bytes, paths, content-derived digests, normalized digests, and
  source-derived revision material out of Debug output, with content digests
  private to the admission implementation;
- bounds compatibility diagnostics and byte-truncates redacted diagnostics;
  and
- makes store empty/reload-failed/generation-exhausted states explicit while
  preserving the last snapshot and refusing `require_current` during failed
  reload health.

Host startup/CLI/hydration migration, provider-specific admission, and later
authority publication fencing remain outside this row’s approved scope.

## Regression coverage added

Focused tests now cover:

- second-statement dotted-key depth, nested adjacent arrays, table inheritance
  with quoted dots, physical multiline line edges, root/table/inline members,
  and node/string budgets;

  Debug output;
- valid/rejected pure admission leaving process-global remote policy unchanged;
  and
- default store behavior, last-good retention with failed-reload health,
  publication fencing, and generation exhaustion.
