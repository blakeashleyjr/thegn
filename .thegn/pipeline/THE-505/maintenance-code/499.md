# THE-505 dispatch 499 — chunk 3 capture

verdict: implementation-ready

Implemented the approved chunk-3 capture adapter without startup or authority
wiring:

- Added frozen process capture for cwd, HOME/config/state/app roots, selected
  profile, opaque source identities, mapper-requested environment, CLI
  overrides, and normalization path context.
- Bound base/profile reads to the core source budget and route captured bytes
  through `config_admission::admit`, preserving implicit-absent first-run
  defaults while making explicit and selected-profile absence fatal.
- Preflighted non-DB layers before exactly one strict host-state capture, then
  admitted the same frozen layers with the captured host snapshot. Genuine DB
  absence becomes an empty snapshot; state errors remain errors.
- Added platform dispatch plus opened-file bounded readers for Linux, macOS,
  and Windows. Linux uses the existing O_PATH/local-namespace contract;
  macOS uses O_NOFOLLOW/O_NONBLOCK; Windows uses an opened handle and
  `FILE_FLAG_OPEN_REPARSE_POINT`. Unsupported platforms refuse typed.
- Added injected source/profile/environment/state regression fixtures and
  opened-file fixtures covering first-run versus explicit missing, selected
  profile failure, frozen inputs, invalid UTF-8, oversize, replacement,
  symlink, FIFO, and bounded reads. Existing strict WAL/schema fixtures remain
  authoritative for host capture.
- Added `HostDefinitionsSnapshot::empty` for the explicitly classified absent
  state source.
