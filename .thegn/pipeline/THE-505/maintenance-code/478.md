# THE-505 maintenance code handoff — native dispatch 478

verdict: implementation-ready

## Scope delivered

Implemented the primary-approved chunks 1 and 2 only: a substrate-free,
injected-source configuration admission boundary and strict layer composition.
The boundary now:

- scans captured UTF-8 TOML before normalization/parsing with source, line,
  depth, table/container, member, node, string, and deterministic-work limits;
- distinguishes implicit absent defaults, explicit missing sources, unreadable
  and invalid-UTF-8 sources, parse/schema/semantic/profile/env/CLI/host errors;
- composes defaults → base → selected profile → the existing env mapping →
  `--set` overrides → the existing strict host snapshot composition;
- rejects unknown keys, warning/default enum fallbacks, invalid supplied env and
  CLI values, duration/schema violations, and semantic violations before
  constructing `AdmittedConfig`;
- records bounded compatibility diagnostics, redacted source identities, full
  domain-separated digests, normalization version, host schema, and immutable
  provenance; and
- provides an `AdmissionStore`, generation publication, and real
  `require_current` revision fencing for later host authority wiring.

The legacy `Config::load_layered` / `try_load_layered` APIs remain present and
explicitly marked for later removal/migration. The new admission path never
calls their fallback-to-default behavior.
