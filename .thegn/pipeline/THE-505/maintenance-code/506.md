## Scope delivered

reload, CLI authority, provider validation, migration, and launch publication
remain unwired as required.

- Fixed selected profile read modeling. A selected missing profile is admitted
  as `SourceInput::Absent` and refuses as `ProfileInvalid`; a present empty
  profile remains a present empty byte layer. Profile read failures are
  returned before the host-state callback is reached.
- Added CLI profile selection and an explicit frozen `ProfilePaths` contract.
  CLI selection wins over captured environment selection, default keeps the
  legacy roots, named state is rooted at `<profile-root>/state`, and an already
  rerooted caller cannot be double-rerooted. Profile and derived state/worktree
  paths are checked after every join before identity retention or cloning.
  The selector is pinned into the frozen environment view without mutating
  process environment.
- Added the pure `profile::resolve_for_capture` helper for the pre-reroot
  fallback; the eventual single-threaded adapter can pass `profile::active()`
  as the already-resolved frozen root.
- Strengthened Linux and macOS opened-file identities with full mtime/ctime
  seconds and nanoseconds, retained descriptor checks, and post-read O_PATH or
  opened-file pathname revalidation. Linux still permits resolved regular-file
  symlinks under its documented stable local-filesystem namespace. macOS
  rejects final symlinks after no-follow regular-file preflight. Windows now
  uses the existing Win32 owned-handle identity and rejects all final reparse
  points; it does not use unstable `MetadataExt` file-index fields.
- Added same-length mutation and equal-size replacement regression fixtures,
  explicit Linux tmpfs fixture skip reporting, profile precedence/binding

  schema, orphan sidecars, and busy DB refusal. Invalid profile layers assert
