# THE-695 implementation report — dispatch 704

Verdict: implementation-ready

## Changes

- Removed `Feature::Trackers` from the channel enum, exhaustive feature list,
  identifiers, stability match, config clamp, host clamp bitmap, and Kaneo's
  experimental command gate. Kaneo now follows the ordinary ungated command
  path. Removed tracker-specific clamp notices/refusals from `wt`, `issue`, the
  daemon issue endpoint, and the issues panel. Generic clamp recording and
  diagnostics remain; `config get` retains generic notices for still-gated
  sections.
- Added `stable_layered_config_keeps_linear_trackers_across_base_profile_and_repo_overlay`
  in `crates/thegn-core/src/config_tests.rs`. It loads `provider` from the base,
  `providers` from a profile, and an `issue_accounts` entry from `.thegn.toml`,
  applies the stable clamp, then verifies the effective tracker and synthetic
  account token survive.
- `config get` previously serialized `IssueAccount.token` without redaction.
  It now applies the canonical `thegn_core::redact::redact_json` masking to JSON
  values and issue-account subtrees, and masks direct secret-key lookups. Added
  a synthetic-canary regression test for both `issues` and the direct token
  path. The config-get warning is emitted separately and contains no config
  values.
- Updated the active release-channel spec, release-channel help, config
  example, and archived release-channel artifacts to describe trackers as
  stable. Historical audit reports under `docs/audits/` were left unchanged.
- Inspected the two no-tracker smoke assertions in `test/smoke.sh` (lines
  1949–1952). They only require nonzero exit status and remain valid; the
  underlying no-tracker message is unchanged.
