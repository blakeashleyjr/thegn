# THE-696 implementation report

## Verdict

implementation-ready

## Scope implemented

- Added `thegn wt folder <worktree> <name>` and `--clear` to unfile a worktree while preserving its folder row.
- Added `thegn wt new --folder <name>` for single-repo and `--program` creation. Filing happens after worktree registration; assignment failures roll back the created worktree and return an error.
- Folder names are trimmed and empty names are refused before folder creation. Existing names are found case-insensitively within the repo. Assignment reads the persisted folder row and uses `set_worktree_folder_if_identity`; mismatches return an error.
- The standalone command discovers the worktree and main repo from Git, registers the worktree row before filing, and rejects paths outside a Git worktree.
- Folder deletion behavior remains the existing unfile-on-delete contract and is covered by a regression test.
- No config, capability catalog, control API, plugin, MCP, schema, or TUI changes.
