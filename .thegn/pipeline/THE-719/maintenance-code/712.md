## Implementation

- Changed `WorkspaceStore::ensure_folder` to accept `workspace_name` and
  `workspace_kind` (`crates/thegn-core/src/store/workspace.rs:244-250`).
- `Db::ensure_folder` now runs the tombstone check, workspace registration,
  case/whitespace-insensitive folder lookup, and folder creation in one
  transaction (`crates/thegn-core/src/db_workspace.rs:741-765`). Tombstone
  query errors propagate. A tombstoned workspace returns the typed
  `WorkspaceTombstonedError` (`crates/thegn-core/src/store/workspace.rs:10-15`)
  with its path and re-add guidance, before either row is written.
- Added the shared host identity helper
  (`crates/thegn-host/src/workspace_identity.rs:7-23`): basename with
  `workspace` fallback and `repo`/`dir` kind. Hydration uses it at
  `crates/thegn-host/src/hydrate.rs:808`. It accepts reliable known-kind hints:
  merge lifecycle and `wt folder` provide `repo`; TUI handlers use the
  hydrated workspace kind when present. The Git fallback therefore runs only
  when kind data is unavailable, and TUI callers invoke it inside
  `spawn_blocking`.
- Updated every production `ensure_folder` caller: `cmd/wt.rs:423-453` retains
  its early tombstone preflight (now propagating query errors) and removes the
  duplicate `put_workspace`; `merge_lifecycle.rs:263-266`,
  `handlers/sidebar_folder.rs:98-105`, and
  `handlers/sidebar_actions.rs:126-134` pass shared identity. Updated test and
  support callers in `db_tests.rs`, `merge_lifecycle.rs`, and
  `integrate_persistence.rs`. The sibling-facing
  `file_registered_worktree`, `check_folder_fileable`, and
  `clear_folder_if_registered` signatures remain unchanged.

## Regression coverage added

- `ensure_folder_creates_then_reuses`: starts without a workspace row, verifies
  both workspace and folder registration, then checks case/whitespace reuse.
- `ensure_folder_refuses_tombstoned_workspace_without_writes`: checks the typed
  error and that neither workspace nor folder is created.
- `ensure_folder_preserves_existing_workspace_kind_and_position`: checks an
  existing `dir` kind and explicit sidebar position survive registration.
- `enqueue_registers_unopened_workspace_and_files_merging_folder`: removes the
  workspace immediately before `LifecycleEvent::Enqueued`, then checks the
  workspace, `Merging` folder, and filed worktree.
