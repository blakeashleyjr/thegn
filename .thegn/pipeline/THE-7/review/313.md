## Small fixes committed during review

Commit `b2fff882` (`fix(the-7): harden builder input failure paths`) fixes and
tests three failure paths:

- The token editor now accepts only `#` and ASCII hex digits. Previously a
  printable multibyte character advanced the byte cursor by one and the next
  insertion could panic at a non-character boundary.
- Unix no-follow reads also use nonblocking open semantics. Previously an
  import targeting a FIFO could block before handle metadata rejected the
  non-regular file; the same flag closes the scan replacement race.
- Theme-store request sends now return errors. Import, Save, Apply, and Scan
  surface a disconnected worker instead of swallowing the enqueue failure and
  leaving the modal permanently pending.
