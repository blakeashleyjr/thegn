# THE-293 maintenance-code — native dispatch 719

verdict: implementation-ready

## Scope implemented

- Added a platform-owned bounded helper runner. On Unix it uses the existing
  grouped-spawn seam, null stdin/stdout/stderr, one five-second total deadline,
  process-group SIGKILL, direct-child wait/reap, and a bounded group-settlement
  check. Typed outcomes distinguish spawn, exit, timeout, cancellation, reap,
  and descendants that fail to settle.
- Lifted the existing `monitor_action::run_bounded` implementation into that
  platform runner and kept its existing `Option<bool>` caller projection. The
  non-Unix monitor fallback retains its previous direct-child behavior.
- Routed both provider argv playback and legacy `sh -c` command mode through
  the Unix runner. Shell command semantics remain unchanged; provider paths
  remain separate argv items. A timeout returns control to the serial playback
  loop so later accepted jobs can run.
- Replaced one-thread-per-reload with one snapshot worker and a one-slot latest
  request mailbox. Generation advancement and request replacement are
  linearized with snapshot publication. Snapshot scans observe shutdown between
  filesystem entries.
- Added explicit sound shutdown to the existing post-loop shutdown path. It
  stops admission, sets helper cancellation, drops the playback sender, clears
  pending reload work, and joins the owned workers. Workers use weak runtime
  references so their receive loops do not retain a sender/runtime cycle.
- Updated notification help to state the Unix helper deadline and the current
  Windows direct-child limitation. Queue-full behavior remains unchanged per
  the approved cut; no bell-on-overflow behavior was added.

## Regression coverage added

- Unix fake-helper tests cover a deadline kill and direct-child reap, an early
  parent exit with a surviving-grandchild candidate, cancellation, and running
  a later helper after a timeout.
- A reload-storm test verifies that the pending mailbox retains only the latest
  generation/configuration.
- Existing legacy command failure coverage now invokes the bounded runner.

The tests exercise the runner and mailbox seams; the full host lifecycle paths
still require the centrally scheduled Rust test gate. Queue-overflow fallback,
Windows Job Object containment, and an end-to-end `SoundRuntime::shutdown`
fixture are outside this approved dispatch scope or remain unverified.
