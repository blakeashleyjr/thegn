## Review and fixes

- Audited the watcher/config/player restart path and found that queue/source
  requests were tagged only with the panel-local generation. A restart could
  leave the displayed snapshot unchanged while an old response was still
  accepted. Added the watcher generation to `MediaRequest` and reject checks,
  plus a regression test for old queue/source deliveries after restart.
- Audited media async failure paths. Transport/playlist snapshot failures and
  queue fetch failures now emit `thegn::media` debug diagnostics instead of
  silently collapsing to `None`/an empty queue.
- No shell interpolation was introduced for player, playlist, or queue IDs;
  provider dispatch remains through typed APIs/argument vectors. No new
  capability, control-schema, completion, env-overlay, or platform-ratchet
  drift was found.
