## Findings fixed

1. **Inactive managed files could conceal user edits.** The seed plan omitted
   gate/phase-inactive skills and legacy MQ commands. If a previously managed
   file was then edited, its old `.git/info/exclude` entry remained and hid the
   user-owned edit from `git status`. Inactive managed paths are now surveyed:
   byte-identical managed files remain ignored, while modified or unmarked
   files are exposed.
2. **Removed/excluded assets retained stale local-ignore entries.** Exact
   exclude patterns are now removed when an asset is excluded or a deprecated
   managed file is successfully removed.
3. **Local-exclude failures were swallowed.** Reads, writes, and symlink/access
   failures from `.git/info/exclude` now propagate into explicit seed failure
   reporting and produce a nonzero result rather than a false success.
4. **Configured discovery followed a symlinked `SKILL.md`.** User packages now
   require a regular, non-symlink document; discovery is marked incomplete on
   rejection so destructive reconciliation stays disabled.
5. **Unknown configured harnesses silently fell back to Claude.** Claude is now
   only the empty/default-config fallback. A config containing only unknown
   targets emits diagnostics and writes no harness files.
6. **Two sandbox secret-argv tests inherited ambient state.** Their env-file
   writes could fall back to argv when the ambient state directory was
   read-only, creating a false secret-leak assertion. Both tests now isolate
   `XDG_STATE_HOME` in their temporary fixture.
7. **The new symlink regression violated the platform-cfg ratchet.** Symlink
   creation now goes through the existing `platform::symlink_file` seam, with
   no platform conditional in `skill_seed.rs`.
