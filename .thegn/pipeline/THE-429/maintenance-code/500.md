## Scope implemented

- Hardened `nix/detect-legacy-post-checkout.py` to support only POSIX process
  groups and no-follow primitives, refusing unsupported platforms before any
  subprocess is created.
- Git queries now scrub repository, index, object, namespace, discovery, and
  command-local config redirection variables before the first query while
  retaining normal HOME/XDG/global-config inspection and the existing explicit
  command-scope `core.hooksPath` refusal.
- Bounded Git capture now kills only the isolated process group on timeout,
  overflow, or capture error, closes both pipes, and finitely reaps the direct
  leader. EOF is followed by a bounded `wait()` so a successful Git process is
  not killed during the normal EOF/status race.

  cleanup regressions, the EOF/status race, A-cwd/B-environment repository
  identity coverage, and read-only preservation of regular, directory,

  including bytes, inode, and mtime snapshots around shell setup and checkout.
  The native fixture also asserts that worktree creation does not seed that
  config.

  release binary, or `/home/blake/code/thegn/target/release/thegn`, and to
  report clearly when the native fixture is unavailable.
