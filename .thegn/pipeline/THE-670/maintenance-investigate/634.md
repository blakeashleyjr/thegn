## Blocking conflicts and unresolved dependencies

1. **Timeout mismatch:** issue capture and coordination say preserve a 20-second native timeout. The exact branch currently sets `OCTOCRAB_REQUEST_TIMEOUT` to **10 seconds** (`native.rs:412-415`) and explicitly documents why. `TrackerHttpClient` has a 20-second default. The plan should preserve the branch's observed 10-second ceiling (including while waiting for the shared permit and during connect/TLS/read), unless the primary intentionally supersedes the branch with the capture’s 20-second requirement. It must not silently default to 20 seconds, which would lengthen a stalled refresh.
2. **HTTP API / scope mismatch:** `TrackerHttpOperation::json` discards error bodies and maps all 403s to `Auth`; therefore it cannot retain the old `403 + “rate limit” -> RateLimited` behavior or the old other-status message classification. An exact mapping needs a small bounded response-envelope operation in `crates/thegn-svc/src/issue/http.rs` (status + bounded JSON/body, retaining redirect/encoding/content-type/body/deadline checks) and a production operation deadline override, then have native classify the response. The coordination scope excludes `issue/http.rs`. Reusing `json()` as-is would lose the 403 rate-limit distinction and violate the requested exact classification map; bypassing it with a separate reqwest client would duplicate policy and violate coordination. Primary must approve this minimal scope expansion or choose an explicitly reviewed contract change.
3. **Audit artifact scope:** acceptance asks to remeasure and update `docs/audits/dependency-audit-2026-09-15.md`, while the primary scope list excludes that file (and omits the necessarily updated `Cargo.lock`). Include those generated/recording changes in implementation scope if the acceptance criteria remain binding.
4. No external/network tests are allowed by coordination. Test fixtures should use a local Axum server as the issue requests. A stalled local response can verify the absolute deadline and circuit behavior; an actual TLS-handshake stall is not reproducible in a no-network fixture, so assert the shared reqwest connect timeout and overall operation deadline by inspection as well.
