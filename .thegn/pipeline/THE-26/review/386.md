## Findings

1. High — header-shaped credentials bypass the redaction boundary. `redact_text_line` in `crates/thegn-core/src/log_redact.rs:102-145` only splits on whitespace and delegates to argv rules that recognize `--flag VALUE`, `--flag=VALUE`, and `KEY=VALUE`. A normal command/log shape such as `curl --header Authorization: Bearer live-token` is returned unchanged: `Authorization:` is a non-flag token, so the `auth` keyword is never consulted. THE-26 applies this function to the WARN ring and historical crash reports before putting them in a support bundle, so those values can be disclosed. The tests cover only flag and assignment forms and do not cover `Authorization:`, `Proxy-Authorization:`, cookies, JSON, or colon-delimited fields. Fix the parser to handle the documented header forms (or make the bundle input a structured, secret-free format), and add regression tests for each supported shape.

2. High — crash-report enumeration is symlink-following arbitrary-file inclusion. `diagnostics::report_names` accepts any basename ending in `.txt` (`crates/thegn-core/src/diagnostics.rs:355-366`), `list_reports` turns it back into a path, and `crates/thegn-host/src/cmd/bundle.rs:85-100` calls `std::fs::read(&report)`. `read` follows a `crash/evil.txt -> /sensitive/file` symlink, placing that file’s contents into the archive. This is reachable whenever a process can write the crash directory; the new permission contract explicitly continues after failure to restrict that directory, so the “owner-only” assumption is not sufficient. Filter with `symlink_metadata`/regular-file checks and test a symlink to a sentinel file.

3. Medium — retained report read failures are swallowed. The same bundle loop uses `if let Ok(body) = std::fs::read(&report)` and otherwise emits no manifest entry or warning. An unreadable, raced, or dangling retained report is silently omitted although the manifest/documentation says the bundle contains all retained crash reports. Return/report the omission (without failing the whole bundle if that is the intended degradation), and add a failure-path test.
