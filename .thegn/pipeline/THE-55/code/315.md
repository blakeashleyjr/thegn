# THE-55 code completion — dispatch 315

## Verdict

PASS. The source-coldness TOCTOU finding from review 306 is closed with
cross-process guards retained for the full real migration.

## Implemented

- Added a shared lifetime profile-owner lock held by every compositor,
  including advisory duplicate instances, with migration taking the exclusive
  side. A compositor starting after migration begins is refused; any compositor
  that started first keeps migration out until it exits.
- Retained the legacy singleton inside the migration guard so a pre-protocol
  compositor also fails closed. The real move acquires both profile fences
  before either database opens and holds them through target commit, source
  cleanup, notification, and reporting.
- Added a per-worktree shared daemon-open lock held from request entry through
  session registry insertion. Migration holds its exclusive side, so an open
  either becomes visible before the initial live-session listing or is refused
  until migration completes. Ordinary concurrent opens remain allowed.
- Kept dry-run write-free: it probes existing owner/singleton locks without
  creating the profile root or lock files.
- Added deterministic regressions for late compositor startup, daemon open
  after the initial listing, surviving advisory duplicate compositors, existing
  owners, concurrent ordinary opens, and dry-run no-write behavior.
