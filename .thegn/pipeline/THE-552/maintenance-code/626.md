## Scope delivered

Implemented the primary-approved replay fix in `replay.rs` and
`replay_overlay.rs`. The source review found no remaining design blocker. This
handoff does not claim `implementation-ready`: CPU constraints prohibited the
required Rust compilation and test runs.

- Each retained event now carries its own monotonic sequence, including resize
  events. Reconstruction applies all retained events with `at_ms <= requested`
  and returns the next sequence cursor for playback.
- Replay overlay playback advances by sequence, so equal-millisecond events and
  newly appended events at the current timestamp are consumed once. Backward
  seeks rebuild the emulator. A changed retained-front sequence clamps the
  cursor to the retained start and rebuilds scratch state.
- Search samples only after a complete timestamp group, so its reported time
  reconstructs the same visible grid. Existing strict `>` forward and `<`
  reverse search semantics remain unchanged.
- Added deterministic regressions for bytes and resize at timestamp zero,
  multiple events at zero, same-timestamp final-frame search agreement,
  repeated sequence feeds, backward rebuild, same-time append/resumption, and
  eviction overtaking the overlay cursor. No sleep was added to tests.
