# THE-676 adversarial source review — native dispatch row 524

verdict: revisions-needed

## Blocking source finding

1. **Poisoned cache does not fall back to an uncached probe** —
   `crates/thegn-core/src/util.rs:661-672` (and the insert path at
   `:677-684`). The primary plan requires that any cache-lock problem be
   non-fatal _and_ bypass the cache for an uncached `which_path` probe. The
   implementation recovers `PoisonError` with `into_inner()` and then still
   reads the poisoned map, so a positive entry can return `true` without any
   probe after the lock has been poisoned. A panic while holding the cache
   lock can therefore leave callers trusting a potentially inconsistent/stale
   cache indefinitely, contrary to Amendment 2. Detect the poisoned lock and
   return the uncached probe result without reading or writing the cache; if
   the second lock (the positive insert) is poisoned, return the already
   computed probe result without inserting. The new test-only regression
   `crates/thegn-core/src/util.rs:1683-1702`
   (`poisoned_positive_cache_falls_back_to_an_uncached_probe`) intentionally
   exposes this defect and is expected to fail until the production helper is
   corrected.
