# THE-716 — implementation-ready

## Changes

- Published basic-list demand from the event loop through an atomic signal:
  `None` when neither panel nor monitor exists, `Summary` for
  `chrome.panel.is_some()`, and `Detail` for `monitor.is_some()`.
  `containers_live` remains a separate stats/df enrichment gate. See
  `crates/thegn-host/src/run.rs` and `hydrate_schedule.rs`.
- Added named listing cadences in `hydrate.rs`: None = zero periodic work,
  Summary = 60 seconds, Detail = 5 seconds. The worker serves None→Summary and
  Summary→Detail immediately, and otherwise tracks elapsed time from the last
  listing. An idle demand check adds no wake source and performs no I/O.
- Container results are sent and wake the loop only after demand rises, a
  rendered snapshot field changes, or a visible aggregate footprint changes.
  Summary comparison uses name, backend identity, image, status/health, and
  ownership; detail comparison also includes CPU, memory, and network values.
  Aggregate df remains on its 60-second cadence while stats are live.
- Container listing checks only fresh cached local `available()` results.
  Unknown or absent backends are skipped without probing; Docker remains the
  fallback when Podman returns no rows. Health is recalculated from cached
  rows when hydration changes the active worktree.
- The `gh` cadence was left unchanged per primary scope; THE-717 owns its
  remaining idle-spawn gate.

## Regression tests added

- `no_container_demand_never_lists_or_wakes_for_container_slots`
- `summary_demand_uses_sixty_second_cadence`
- `detail_demand_uses_five_second_cadence`
- `rising_container_demand_lists_immediately`
- `identical_container_snapshot_does_not_wake_but_a_change_does`
- `summary_container_equality_ignores_metrics_but_detail_equality_includes_them`
- `ambient_container_listing_runs_ps_only_for_cached_present_backends`
- `ambient_container_listing_with_no_present_cache_is_empty_without_ps`
- `container_health_recomputes_for_active_worktree_from_cached_rows`

The None-demand regression is designed to fail on the old ticker: its
unconditional 5-second slot calls `send_containers` at tick 10 and sets
`wake = true`. It was not executed here because the dispatch instruction
prohibits Cargo while batch Rust validation is centrally scheduled.
