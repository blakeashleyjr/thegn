## Implemented scope

- Replaced `[media.mpd].password: Option<String>` with a typed, redacted `MpdSecretRef`. It deserializes existing bare strings as literal compatibility values, supports `keyring:`, `env:`, and `file:` references, serializes the configured literal/reference for compatibility, and presents a string schema. The containing MPD config and the individual wrapper both redact Debug.
- Kept core lowering substrate-free and stopped transferring the config credential into `ResolveOpts`.
- Added an additive host broker API with distinct missing, unavailable, and denied errors while retaining the existing `Option<String>` API for other callers. Every configured resolution emits one metadata-only audit event.
- Added `media:mpd` host credential resolution with a moved `MpdPassword` owner. MPD endpoint/options are not cloneable or value-debuggable; secret command and line buffers use `Zeroizing<String>`. `MPD_HOST=password@host` is parsed and audited at the host boundary, and only the sanitized endpoint reaches the leaf. Explicit config credential precedence is preserved.
- Routed every current host `client_for` entry through the shared broker helper: (1) watcher/retry loop in `media_watch.rs`; (2) media operation; (3) playlist activation; (4) player/playlist picker; (5) queue fetch; and (6) source picker in `media_ctl.rs`. Explicit MPD resolution refusal prevents dialing. In Linux `auto`, a credential refusal skips the MPD source while allowing unrelated media sources to continue.
- Added MPD config and `MPD_HOST` forms to the canonical secret inventory and literal detection. Existing secret list/audit/doctor/config-health surfaces consume that inventory. `secret migrate` now rewrites config literals and migrates an active embedded `MPD_HOST` password into the stable `media.mpd.password` key; it explicitly tells the operator to remove the password prefix from the environment because the inherited environment cannot be rewritten by the command.
- Updated the example config to show a file reference without changing the config key.
