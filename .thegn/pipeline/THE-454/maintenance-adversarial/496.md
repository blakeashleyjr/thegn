## Finding

### Medium — declared oversized error bodies are not rejected at headers

Locations:

- `crates/thegn-svc/src/http.rs:532-555` (`discard_body`)
- `crates/thegn-svc/src/calendar/ics_url.rs:147-161`
- `crates/thegn-svc/src/calendar/caldav.rs:360-393`
- `crates/thegn-svc/src/calendar/caldav.rs:472-478`

`discard_body` bounds the accumulated bytes only after it receives stream
chunks. It never checks `response.content_length()` against
`MAX_ERROR_BODY_BYTES`. An endpoint can therefore send a `500`/`401`/`409`
header advertising more than the 8 KiB diagnostic cap and then never send the
body. The calendar task waits for the read/operation deadline instead of
rejecting the response at header admission. This leaves a slow resource/FD
hold and does not meet the issue's requirement that error bodies be bounded
independently of framing. The existing chunked oversized-error fixtures prove
the later streaming check, but not this declared-length bypass.

Added regression:

- `crates/thegn-svc/src/calendar/tests.rs:666-727`,
  `declared_oversized_error_body_is_refused_without_waiting_for_payload`.

It uses raw HTTP for both ICS and CalDAV, advertises
`MAX_ERROR_BODY_BYTES + 1`, sends no payload, applies a bounded outer timeout,
and requires `CalendarError::BodyLimit`. It is expected to expose the current
source defect until the shared discard path performs the header check. The
CalDAV literal coverage at `calendar/tests.rs:857-861` also now exercises the
mapped-loopback refusal through the real backend.

## Additional acceptance gap

The success paths validate ICS/DAV media types, but all error paths validate
only `Content-Encoding` and then call `discard_body`; they do not validate the
response media type. This is visible at the status branches cited above and is
the remaining source-level gap against the issue's explicit statement that
error responses lacked content-type validation. If the intended compatibility
policy applies to body-bearing error responses too, add a focused wrong-media
fixture for both backends and reject it before draining; otherwise document the
deliberate error-body exception in the transport contract and acceptance
evidence.
