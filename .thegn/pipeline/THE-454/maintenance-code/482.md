## Implemented

- Fixed `webcal://` normalization by rewriting the validated scheme before
  URL parsing, preserving authority/path/query while rejecting userinfo and
  fragments.
- Switched literal destination admission to typed `url::Host::Ipv4`/
  `Ipv6`, including mapped IPv4 normalization, so bracketed IPv6 and mapped
  loopback literals cannot bypass policy.
- Replaced broad address heuristics with explicit reviewed public IPv4 and
  IPv6 global-unicast policy. Boundary cases retain ordinary public portions
  of 192.0/16, 198.51/16, and 203.0/16; documentation, reserved,
  benchmarking, translation, and transition ranges remain denied. The
  private opt-in adds only intentional local unicast ranges and still denies
  unspecified, multicast, broadcast, reserved, and documentation addresses.
- Capped resolver answers and fail closed on overflow or mixed allowed/denied
  answers. The same checked answer set is passed to reqwest. Added an injected
  resolver test seam for actual connection-path, mixed-answer, and rebinding
  refusal fixtures.
- Added request `Accept-Encoding: identity`; validated every Content-Encoding
  value and rejected repeated/ambiguous encodings. Content-Type validation is
  case-insensitive, parameter-aware, and refuses missing/repeated values.
- Reworked bounded response accumulation to use checked arithmetic,
  fallible exact reserve, and capacity assertions before extending. Existing
  tracker users continue through the same bounded reader. Added exact-cap,
  cap-plus-one, declared-length, chunked, encoded, error-body, and capacity
  regression coverage.
- Bounded retained ICS ETags and CalDAV sync tokens. CalDAV XML request
  escaping now computes the exact expanded envelope size before one bounded
  allocation/write. CalDAV parsing fails closed on oversized retained href or
  sync-token state.
- Added deterministic total-header and never-ending-body deadline fixtures;
  the existing connect/read-idle/absolute deadline configuration and one-shot
  CalDAV fallback continue to share the original absolute deadline.
- Added backend-level coverage for all 301/302/303/307/308 redirect statuses,
  relative/absolute locations, body non-replay, public literal refusal,
  mixed-case ICS/DAV media, proxy-environment isolation, pool reuse across
  reconstructed accounts, auth/validator isolation, cookie non-retention,
  and host DB diagnostic redaction.
