# THE-482 implementation — native dispatch 522

Verdict: implementation-ready.

## Implemented

- Replaced the `MonthGrid::week_numbers()` first-cell ISO heuristic with a
  checked configured-start week calculation. Week 1 is the configured-start
  week containing January 4 (the ISO four-day minimum-days rule). Monday-first
  remains ISO-8601; Sunday- and Saturday-first labels follow their row
  boundaries. `DayCell.iso_week` is unchanged.
- Kept the calculation total at chrono's representable boundaries: year/date
  probes use checked arithmetic, and the minimum-date week-one boundary is
  handled without constructing an unrepresentable date or panicking.
- Added calendar regression coverage for Monday compatibility against the
  existing per-cell ISO values, January 2021 Sunday/Saturday crossover rows,
  and December 2026 week-53/week-1 transitions for Monday, Sunday, and
  Saturday starts.
- Updated the approved terminology surfaces in the grid/module docs, the
  `show_week_numbers` schema/help description, the example config, and the
  two explicitly approved comment residues. Auto behavior is documented as
  using the locale-resolved `week_start`; no new key or locale numbering table
  was added.
