# THE-412 maintenance code — dispatch 729

**Verdict:** implementation-ready

## Implementation

- Replaced `HostSource::new` with fallible `try_new` construction and a typed
  spawn error. The Observe builder propagates that error into the existing
  `SlotState::Failed` path, logs its cause, and marks the app chip as failed.
- The source owns its worker handle. The worker keeps the one-second sampling
  cadence with `park_timeout`; drop sets cancellation, unparks, and joins. Stop
  checks fence publication after sampling and before appending. A worker panic
  is logged after join.
- The host supplies its `platform::qos::Background` setter through a thread
  entry callback, keeping the platform module dependency out of `gtui-query`.
- Added regression coverage for injected spawn failure, visible failed-slot
  state, prompt idle shutdown, repeated construction/drop, worker panic,
  poisoned ring handling, pre-epoch clock fallback, and a query future that
  outlives source drop.

## Remaining acceptance gaps

- Idle shutdown wakes and joins promptly, but `JoinHandle::join` cannot enforce
  a hard deadline if `StatsSampler::sample()` itself stalls. Making that call
  interruptible would require a sampler API change beyond the approved plan.
- Query-engine task cancellation remains deferred as directed by the primary
  plan. A hung remote query can retain the source through the engine's shared
  ownership; this change does not prove that it is released by an app shutdown
  deadline.
- Runtime behavior and compilation remain unverified until the listed commands
  run.
