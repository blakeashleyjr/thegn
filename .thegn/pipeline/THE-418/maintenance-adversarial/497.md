### F-01 — Required executable first-launch regression is still missing [medium]

The hostile fixture in
`crates/thegn-host/src/agent_tests.rs:183-322` is useful, but it only calls
the resolver/composer seams at lines 266-291 and then checks marker files at
lines 298-319. It never sends a batch through the actual materialize or
prewarm drain, calls `Panes::spawn_argv_env`, or exercises the startup/open
path. It therefore cannot detect a regression where the resolver remains
side-effect-free but the launch boundary invokes a host login shell whose
direnv hook evaluates `.envrc`.

This is specifically contrary to the primary launch-review instruction that
source-grep and boolean/composition tests are insufficient: the required
fixture must fail against the old behavior at an executable launch seam. The
uncovered production paths are the automatic sibling worker at
`crates/thegn-host/src/run.rs:8576-8695` and focused materialization at
`crates/thegn-host/src/handlers/materialize.rs:181-305`.

Required follow-up: add a focused executable integration regression with
hostile `.envrc`, executable fake `direnv`/`nix`, and a hostile shell sentinel;
drive the real first-launch/prewarm drain seam and assert no host process or
marker runs before an explicit scoped host action. Keep the explicit focused
host-launch preservation test separate.

### F-02 — Attach-only prewarm drain has no route-level regression [medium]

The new host rejection source path is present before and after remembered-agent
relaunch at `crates/thegn-host/src/run.rs:8639-8681`, and the drain has the
intended attach-only branch at
`crates/thegn-host/src/handlers/provision.rs:543-555`. However, current tests
only exercise `reject_host_prewarm` with fabricated specs
(`agent_tests.rs:100-130`) plus the resolver-level remembered-agent test. They
do not deliver `SpecOrigin::Prewarm` with `PrewarmSkipped` and a live attach
target through `drain_specs`.

A future regression could therefore either spawn a host replacement or drop a
live daemon attachment while all current tests remain green. Add a route-level
drain test that supplies a skipped prewarm and an attach target, asserts the
target is adopted, and asserts no fresh host pane is spawned.
