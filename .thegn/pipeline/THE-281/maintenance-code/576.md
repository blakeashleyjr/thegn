## Implemented

- Replaced the IPv6 `contains(':')` authority heuristic in
  `crates/thegn-svc/src/control/client.rs` with `reqwest::Url::host()` and the
  typed `url::Host` formatter. IPv6 hosts therefore retain exactly one pair of
  brackets; IPv4 and DNS hosts remain unbracketed.
- Kept port serialization based on `Url::port()`, which in the pinned `url`
  2.5.8 behavior omits default `http`/`https` ports while retaining explicit
  non-default ports. The derived `ws`/`wss` URL uses the same normalized
  endpoint.
- Added exact-output regression coverage for IPv6, IPv4, and DNS origins with
  and without ports, including `https://[::1]:8443` and default-port forms.
  Each case asserts the authority, unary request URL, and derived WebSocket
  URL.
- Added a regression assertion that `url` 2.5.8 rejects
  `https://[fe80::1%25eth0]/`. Scoped IPv6 zone IDs are not applicable at this
  dependency version; no parser or dependency was added.
