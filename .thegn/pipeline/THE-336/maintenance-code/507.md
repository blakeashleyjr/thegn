# THE-336 implementation handoff — dispatch 507

Verdict: implementation-ready

Implemented the approved `.thegn/maintenance/primary-plan.md` scope for
bounded LSP messages, recursive projections, diagnostics delivery, retained
state, and host draining. No new user-facing feature or configuration knob was
added.

Changes:

- Added centrally documented inclusive LSP bounds for framing, JSON preflight,
  iterative projections, identities, diagnostics, queues, retained roots/files,
  and completion results.
- Enforced the 8 MiB LSP body limit at frame-header admission while preserving
  the existing 64 MiB bridge default; added depth/node/container/scalar
  preflight before `serde_json::Value` construction.
- Added bounded iterative symbols/hover projections, bounded locations,
  signatures, actions, diagnostic publications, remote errors, and terminal
  control-text sanitization. Overlong or invalid identities are rejected
  rather than truncated.
- Added supervisor-owned root/server/generation authority and per-reader
  sequence stamping. Retired generations remain stale after eviction or
  recreation, and same-document streams from different servers remain
  isolated.
- Replaced the unbounded diagnostics delivery path with a bounded latest-value
  queue, deterministic flooding-root eviction, explicit incomplete health,
  sticky bounded health reporting, clear semantics, and ready-root rotation.
- Bounded the host diagnostics drain to eight publications and 256 KiB per
  iteration with input preemption; bounded outline and hover completion
  channels; retained diagnostics across hydration and surfaced health through
  the existing Problems diagnostics path.
- Added regression coverage for frame admission, deep/wide/large JSON,
  iterative symbol caps, Unicode/control/OSC and identity rejection, queue
  replacement/stale generations/root fairness, multi-server document
  isolation, retained-store caps/sanitization, and an actual fake-LSP deep
  response.
