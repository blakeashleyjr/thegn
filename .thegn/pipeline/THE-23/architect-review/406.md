all three implementation chunks and handoffs, `CONTRIBUTING.md`,
`docs/ARCHITECTURE.md`, the OpenSpec devcontainer contract, and the relevant
ratchet/smoke changes. The core parser/selection/inventory/overlay contracts,

plumbing are present. No small correction was applied in this round.

The implementation is not safe to approve yet:

- The CLI branch in `crates/thegn-host/src/agent.rs` can run before normal
  backend resolution and return `spec: None`, so an explicit backend and the
  effective hardening/network policy are not necessarily honored.
- `devcontainer up` in `crates/thegn-host/src/devcontainer_provider.rs`
  inherits the full host environment while consuming raw repository JSON.
  The allowlist currently clamps only native normalized substitutions; it does
  not constrain `${localEnv:...}` evaluation by the vendor CLI, nor prove the
  provider exec path cannot reintroduce the inherited environment.

These gaps cross the trust boundary and can expose host variables or silently
weaken sandbox policy, so they require a coder revision rather than review
notes.
