## Blocking finding

- **FAIL / high — trusted devcontainer config has a raw-path TOCTOU window.**
  `overlay_devcontainer` parses and trust-gates the selected file, then stores
  only `selected.selected` as a path (`crates/thegn-host/src/handlers/repo_trust.rs:117-186`).
  Later `prepare_sandbox_env` passes that path to `DevcontainerSession::start`
  (`crates/thegn-host/src/agent.rs:348-362`), and `CliProvider::start` passes it
  to `devcontainer up --config` (`crates/thegn-host/src/devcontainer_provider.rs:440-465`).
  A file replacement/edit between those operations is therefore parsed by the
  provider without a new canonical approval. This can reintroduce an image,
  mount, lifecycle command, feature, or other provider-consumed field that was
  absent from the approved parse. The same raw path is retained for later
  `exec`, so the race is not limited to startup. Bind the provider to an
  immutable, content-verified snapshot (preserving config-relative paths), or
  revalidate and reject any changed file before every provider use.
