## Implementation

- Jira transition POST failures now classify definitive 4xx/auth rejection as
  `status` unapplied, while network errors, timeouts, connection resets, 5xx,
  redirects, and other intermediary failures remain ambiguous.
- Ambiguous transition failures use the existing final issue fetch as the
  disambiguator. A requested category confirms success; a failed verification
  returns a typed partial result with `status` in neither applied nor
  unapplied and a bounded `verify before retrying` message. A successful fetch
  showing another category reports status unapplied based on observed state.
- The retry regression now uses a definitive 400 rejection and proves that
  retrying only `status` is safe. A separate ambiguous-failure test proves the
  result does not claim `status` was unapplied, and another proves a final fetch
  can confirm an ambiguously completed transition.
- The fixture server records JSON request bodies. Tests assert the title PUT is
  `{ "fields": { "summary": "new title" } }` and the transition POST carries
  the selected transition id `{ "transition": { "id": "31" } }`.
- No raw provider response body is copied into errors.

## Concrete blocker: control/API structure is not wire-preservable in scope

The accepted P2 control-boundary criterion remains blocked by the existing
published contract:

- `crates/thegn-host/src/daemon/service.rs:1708-1710` converts
  `IssueError::PartialUpdate` into `ControlError::Internal(anyhow!(...))`,
  discarding the field vectors.
- `crates/thegn-svc/src/control/http.rs:150-159` constructs `ErrorBody` with
  only `error` and `code`; `IntoResponse` at `:235-246` exposes only that
  envelope.
- `docs/api/control-v1.json:466-480` snapshots the same two-field `ErrorBody`.

Preserving machine-readable `applied`/`unapplied` fields therefore requires a
control wire schema change and regeneration of `docs/api/control-v1.json`. The
primary instructions explicitly require stopping and reporting if that is
needed, so this dispatch does not change the control model, stringify a fake
JSON payload, or edit the schema snapshot. Direct Rust callers retain the
typed `PartialUpdate`; control clients do not yet receive its fields.
