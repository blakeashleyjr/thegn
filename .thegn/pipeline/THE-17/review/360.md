## Security findings fixed

Committed `40a41236 fix(the-17): harden editor handoff targets`:

1. Host filesystem revalidation used `is_file()`, which followed a
   worktree-relative symlink without proving its resolved target remained under
   the registered worktree. A control request could therefore name a symlink
   to an existing file outside the worktree. The launch edge now canonicalizes
   the worktree and file and rejects resolved paths outside the worktree.
2. `open_editor` mailbox rows had no age limit despite the short-lived intent
   contract. Requests queued while no compositor was running could launch on a
   much later restart. The compositor now drops rows older than 300 seconds,
   matching the existing `adopt_session` mailbox policy and treating future
   timestamps as fresh for clock-skew tolerance.
3. The new handoff worker introduced an unratcheted ignored `waker.wake()`
   result. It now uses the repository's explicit best-effort `drop(...)` form.

Regression tests cover symlink escape rejection, a valid in-worktree file,
expired/boundary/future intent timestamps, malformed/escaping/stale payloads,
and unknown-field rejection.
