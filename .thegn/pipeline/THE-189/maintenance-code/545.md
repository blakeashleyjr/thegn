## Artifact

- Added `hydrate_schedule.rs` with the effective schedule projection, equality
  diffing, one-owner replacement boundary, monotonic generation, cancellation,
  and shutdown join.
- Extended the existing `hydrate_refresh_ticker.rs` worker with a command
  boundary. Replacements coalesce to the latest command, changed slots re-arm
  at a future normal boundary, and unchanged slots retain their schedule.

  a generation envelope. The loop drops stale envelopes before work starts;
  PR, CI, LOC, usage, weather, calendar, and reminder publishers also fence
  cache/result publication against the active generation.
- Untagged refreshes remain event-driven/user-forced, preserving immediate
  manual refresh behavior after a reload.
- Successful config reloads call `ScheduleOwner::reconfigure`; the existing
  error path does not, so an invalid reload retains the effective schedule and
  status message.
