## Changes

- Projected `ScheduleConfig` into the worker's effective 500 ms cadence slots.
  LOC, disk, and auto-fetch values now compare the cadence the worker actually
  runs, so equivalent floored values do not restart the schedule.
- Documented the intentional check-then-commit residual race at
  `generation_is_current`: a reload can admit one stale cache row in the
  narrow window after a check, and the next refresh corrects it. No atomic
  scheduler/cache boundary was introduced.
- Added the missing generation checks immediately before CI failure health
  updates, CI log/autofix side effects, calendar error notifications, weather
  connectivity reporting, PR connectivity reporting, and usage budget alerts.
- Carried an optional schedule fence through scheduled CI detail and PR review
  child jobs. Cache commits and deliveries are fenced; manual and user-forced
  paths remain untagged and unfenced.
- Added `scheduled_delivery` coverage for reload-mid-CI/PR child delivery and a
  production-worker regression that drives `ScheduleOwner`, rapid A→B→C
  replacement, event-loop envelope admission, all seven ticker classes,
  unchanged effective schedule identity, and disabling optional classes while
  the worker remains live.
