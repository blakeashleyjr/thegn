## Scope implemented

- Preserved the existing silent fail-open ladder for DB-open failures, missing
  remembered rows, shell/clean-shell/tool records, and removed configuration
  entries. Only the final `launch_spec_synced_with` error is carried forward.
- Replaced the discarded launch-spec error with a typed intermediate refusal.
  `apply_relaunch` retains the already-resolved shell and emits one WARN-level
  `thegn::agent` diagnostic containing the worktree, remembered agent, stable
  refusal kind, and a bounded actionable reason.
- Classified the current provider-ownership (`DevcontainerLaunchRefused`) and
  sandbox (`SandboxHalt`) errors, with a generic provider/launch bucket for
  ordinary errors and future THE-565 categories.
- Added process-lifetime deduplication by `(worktree, agent, refusal-kind)`.
  No DB state, remembered-agent attribution, attach gate, quiet-split gate,
  shell materialization, daemon adoption, or event-loop behavior changed.
- Added focused regressions for typed provider-origin refusal and a real
  deterministic generic launch-policy error. They assert shell preservation,
  no Codex command substitution, remembered attribution preservation, reason
  classification/observability data, bounded reason handling, deduplication,
  and separate refusal-kind admission.
