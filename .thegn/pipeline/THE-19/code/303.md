# THE-19 row 303 completion

## Verdict

PASS — all three blockers in `review/verdict-2.md` are addressed.

## Implemented

- Hook stdout/stderr readers now share a bounded 250 ms drain deadline after
  the direct shell exits. Output captured before the deadline is retained and
  marked when an inherited descendant pipe remains open; lifecycle completion
  no longer waits for that descendant.
- Detached `session_end` events publish an in-flight completion token during
  the atomic latch transition. Destructive lifecycle workers wait on that token
  off-loop before pre-destroy, runtime teardown, or worktree removal.
- Lifecycle event, individual destroy, and workspace destroy thread launchers
  now return `std::io::Result`. Post-create, pane launch, close, and removal
  callers surface launch failures, while session-start and destroy claims are
  released so retries remain possible.
- Added regressions for inherited background pipe writers, close/delete
  serialization, and worker-spawn failure claim/error handling.
