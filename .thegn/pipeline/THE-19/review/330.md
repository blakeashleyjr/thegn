## Finding and review fix

Adversarial review found one remaining same-process destructive race. Automatic
merge reclaim and expiry used the shared destroy transaction without taking the
per-path claim used by sidebar and workspace deletion. A land or sweep could
therefore overlap interactive deletion and run lifecycle hooks, provider
teardown, and Git removal twice for the same worktree.

Automatic merge cleanup now takes a drop-released scoped destroy claim. If
another deletion owns the path, merge cleanup skips physical mutation, emits a
warning, and still completes the landed queue transition. Regressions cover
claim release, overlap suppression, and the ordinary landed-removal path.

Fix commit: `0a649aa8 fix(the-19): serialize merge reclaim with deletion`.

The remaining reviewed boundaries are sound: the runner clears inherited
environment state and exposes only curated lifecycle context; credential-shaped
and inherited `THEGN_*` variables remain blocked; repo hooks require
content-addressed approval and remain warn-only; private logs are redacted,
bounded, and owner-only on Unix; timeout termination covers process groups;
blocking creation failures roll back; destructive paths are claimed; and the
configuration/default/example/environment-overlay ratchets remain intact.
